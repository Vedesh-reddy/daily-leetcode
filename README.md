# git-contribution-graph-demo

> **SIMULATED EDUCATIONAL GIT ACTIVITY DEMONSTRATION**
>
> Every commit in this repository was generated by a script, and every timestamp was
> set artificially with `GIT_AUTHOR_DATE` and `GIT_COMMITTER_DATE`. The history spans
> 12 Oct 2025 to 7 Oct 2026 but none of it reflects real day-to-day work. This repo
> belongs to a dedicated demo account so the simulated activity never appears on a
> personal profile.

## What this demonstrates

- Git stores an author date and a committer date on every commit, and both can be set freely
- GitHub's contribution graph places commits by **author date** and credits the profile
  that owns the **author email**, regardless of when the commits were pushed
- Square shading is relative: GitHub splits your own non-zero days into quartiles, so a
  varied number of commits per day produces all four shades

## Layout

- `solutions/` — 110 Java LeetCode solutions, each added in its own commit
- `activity/` — one file per simulated day; each extra commit that day appends a line
- `schedule.csv` — the generated plan: date and commit count for every day

## Inspect it

```bash
git log --format='%h  %ad  %s' --date=iso | head
git log --date=short --format=%ad | sort | uniq -c   # commits per day
git cat-file -p HEAD                                  # raw author/committer lines
```
